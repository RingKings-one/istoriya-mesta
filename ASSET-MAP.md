## Replacement order when user-selected photographs arrive

1. Hero / Ruza establishing image — highest visual priority; review desktop and mobile focal points separately.
2. Ruza city feature and supporting urban details — only after subject/location are confirmed.
3. Stories and routes — match each image to the actual story/field-checked route.
4. Cafe — only photographs of the confirmed project venue.
5. Archive — only genuine archive material with provenance, date/creator if known, and usage status.
6. Supporting mood images — replace or remove if they add no editorial information.

## Required metadata before an asset becomes verified

- Stable asset ID and intended role(s).
- Original source filename and source/person who supplied it.
- Actual subject and location, only where known.
- Creator/photographer and credit line, or explicit unknown.
- Rights / permission / license and any usage limits.
- Capture date, only where known.
- Alt text for meaningful images; empty alt for purely decorative images.
- Desktop and mobile focal point / crop review.
- Optimized local AVIF and WebP variants generated by `npm run images:optimize`.
