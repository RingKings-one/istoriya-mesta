# Website Toolkit

Компактный набор проектных инструкций и ссылок для «История места». Это не отдельная AI System.

- Root `AGENTS.md` содержит ограничения проекта.
- Skills находятся в `.agents/skills/` и загружаются по необходимости.
- Подтверждённый стек сайта: Astro 5, static output, `npm run build`, каталог `dist`.
- Не добавлять зависимости без конкретной необходимости.
- Перед публикацией проверить build, адаптив и iOS Safari.

Сайт включён в репозиторий в восстановленном виде. Production-проверка ещё не выполнена.
