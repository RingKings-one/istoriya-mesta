# Original project photography

Place user-selected original raster photographs in this directory, organized by editorial subject (for example `ruza/`, `cafe/`, `archive/`). Keep the original filename and do not place credentials or unrelated files here. The build optimizer reads these originals and writes AVIF/WebP derivatives to `public/images/optimized/`; it never modifies the originals. See the repository-root `ASSET-PIPELINE.md` for naming, metadata and publishing rules.
