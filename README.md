# История места — Astro 5

Многостраничный сайт бренда «История места». Визуальное направление: Cinematic Living Atlas — 60% кинематографичного документального фильма и 40% премиального travel-журнала.

## Страницы

- / — главная
- /cities/ — атлас городов
- /cities/ruza/ — первая глава: Руза
- /stories/ — редакционные истории
- /routes/ — маршруты
- /cafe/ — кофейное пространство
- /archive/ — визуальный архив

## Стек и сборка

- Astro 5, static output
- npm install
- npm run build
- Netlify publish directory: dist

## Визуалы

Для визуальной сборки подключены временные редакционные фотографии с Unsplash. Они помогают оценить композицию, ритм и цвет, но **не являются документальными фотографиями Рузы или реальной кофейни проекта**. Все источники, авторы и правила замены собраны в [ASSET-SOURCES.md](./ASSET-SOURCES.md).

Перед production необходимо заменить временные изображения на отобранные фотографии проекта, сохранить их в public/images/ и переключить ссылки в src/data.ts.

## Проверки

GitHub Actions workflow настроен на Astro build для pull request; фактический статус последнего запуска следует проверять в PR. Браузерный аудит, проверка фактической загрузки внешних изображений и отдельная проверка iOS Safari должны быть выполнены до production-публикации.
