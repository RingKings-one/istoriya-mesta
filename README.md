# История места — Astro 5

Восстановленная многостраничная основа. Направление: Cinematic Living Atlas, 60% кинематографичного документального фильма и 40% премиального travel-журнала.

## Страницы
/, /cities/, /cities/ruza/, /stories/, /routes/, /cafe/, /archive/.

## Сборка
`npm install`; `npm run build`; Netlify publish directory: `dist`.

## Визуалы
В GitHub-ветке временно используется одна композиционная SVG-заглушка, чтобы структура сайта собиралась без отсутствующих JPG. Полный набор визуалов находится в архиве istoriya-mesta-astro-v1-recovered.zip. Перед production необходимо перенести JPG в public/images и переключить пути. Заглушка не является документальной фотографией Рузы.

## Статус
Установка зависимостей, Astro build и браузерные тесты пока не подтверждены.
